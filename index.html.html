Competition Rules

01 — CopyUse the Copy Code button and paste the entire jumbled snippet into any C IDE/compiler.
02 — ReconstructRearrange the existing lines into a valid C program. Read the whole snippet before moving anything.
03 — DebugCompile and fix the order until the program behaves correctly. Do not replace the challenge with a completely new program.
04 — VerifyRun it using the sample input. Your result must match the Expected Output shown on that page.
05 — Think FirstTrack variables, conditions and loop passes. The fastest solution is usually the one you understand before running.
06 — HintsHints are intentionally indirect. They point toward the idea, not the exact line order.
Important: Every question contains the pieces needed for the intended solution. The challenge is to restore the program's logical execution order.

What this tests

Program structure • input/output • operators • if/else • switch-case • loops • arrays • tracing • debugging • code-reading.
